# PPT Content Strategist

**核心定位**：在动手做任何一页 PPT 之前，先用麦肯锡级框架把内容想清楚。本 skill 不涉及设计、排版、工具——只解决一个问题：**你该讲什么，按什么顺序讲。**

## 适用场景

- 要做一份汇报/路演/答辩 PPT，但不确定结构怎么搭
- 素材和想法都有，但理不出核心论点
- 想用金字塔原理、SCQA 等专业方法，但不知道从哪下手
- "帮我想清楚要讲什么"

## 五步工作流

```
1. 内容采访（聊透）→ 2. 金字塔搭建 → 3. SCQA 开场 → 4. MECE 自检 → 5. 逐页大纲输出
```

每步都有明确产出，不走回头路。

---

## 第 1 步：内容采访——先聊透，再动手

**不要一上来就让用户写大纲。** 用以下问题清单像内容策划一样采访，每轮只问 3-5 个问题：

### 采访问题池

**目标与受众：**
1. 这份 PPT 的最终目的是什么？——汇报（要批预算/要获认可）、授课（要让人学会）、说服（要让人改变决策）、展示（要让人了解）？
2. 听众是谁？他们的背景、已知信息、关心点、可能的反对意见？
3. 如果听众只记住**一件事**，你希望他们记住什么？——这将是金字塔的顶层结论。

**内容与证据：**
4. 你手上有哪些材料和数据？哪些是关键数字？
5. 支撑核心结论的 3-5 个最强论据是什么？
6. 有哪些真实案例或故事可以增加说服力？

**边界与约束：**
7. 预计讲多长时间？总页数上限？
8. 有什么绝对不能碰的话题或表述？（政治敏感、商业机密、不成熟的数据）
9. 是投影演示还是会后阅读？——这决定信息密度。

### 采访停止条件

当你能用一句话说出整份 PPT 的中心观点，且清楚哪些内容应该**砍掉**时，进入第 2 步。

> 好的内容策略 = 知道该讲什么 + 更知道不该讲什么。

---

## 第 2 步：金字塔搭建

**原则**：自下而上思考，自上而下呈现。

### 三层结构

```
顶层（结论）= 你的建议/答案
  ├── 中层论点 1（支撑结论的关键论据）
  │   ├── 证据 1a（数据/案例）
  │   └── 证据 1b
  ├── 中层论点 2
  │   ├── 证据 2a
  │   └── 证据 2b
  └── 中层论点 3
      ├── 证据 3a
      └── 证据 3b
```

### 输出格式

```markdown
## 金字塔结构

**顶层结论**：[一句话，听众只记住这个就够了]

**中层论点（3-5个）**：
1. [论点1]
2. [论点2]
3. [论点3]
（4-5，如果需要）

**底层证据**（按论点编号）：
1a. [数据/案例]
1b. [数据/案例]
2a. ...
```

### 质量检验

- **"所以呢？"测试**：每个中层论点能直接支撑顶层结论吗？不能就删。
- **一句话测试**：如果 PPT 只允许有一页，有人能读这一页就拿到全部关键信息吗？

### 反例与正例

| ❌ 坏的顶层结论 | ✅ 好的顶层结论 |
|---|---|
| "关于市场策略的思考" | "建议Q4集中资源攻大客户渠道，预计ROI提升至2.3" |
| "数字化转型汇报" | "数字化投入已进入瓶颈期，下一阶段应从'建系统'转向'通数据'" |
| "团队建设方案" | "团队最大问题是中层断层，建议优先外部引进2名总监级人才" |

## 第 3 步：SCQA 开场框架

金字塔顶端之前，用 SCQA 建立上下文——让听众在 2 页内进入状态。

### 四要素

| 要素 | 含义 | 怎么写 |
|---|---|---|
| **S**ituation（情境） | 大家都认同的现状 | 用听众已知的事实开头，建立共识 |
| **C**omplication（冲突） | 发生了什么变化 | 打破现状的事件或数据——"但是……" |
| **Q**uestion（问题） | 需要回答什么 | 由冲突自然引出的问题——"所以我们需要回答……" |
| **A**nswer（答案） | 你的建议 | = 金字塔的顶层结论 |

### 四种 SCQA 变体

| 变体 | 结构 | 适合场景 |
|---|---|---|
| **标准型** | S → C → Q → A | 通用，最安全 |
| **开门见山型** | A → S → C | 给高管汇报，先给结论 |
| **突出忧虑型** | C → S → Q → A | 需要制造紧迫感 |
| **突出信心型** | Q → A → S → C | 先抛问题让听众共鸣 |

### 输出格式

```markdown
## SCQA 开场

**S（情境）**：[1-2句]
**C（冲突）**：[1-2句，必须具体——最好有数字]
**Q（问题）**：[1句]
**A（答案）**：[1句，= 金字塔顶层结论]

**建议变体**：[标准型/开门见山型/突出忧虑型/突出信心型]
```

### 示例

```markdown
**S**：我社连续五年市场份额稳定在15%，编辑团队稳定、出书品质行业公认。
**C**：但2025年数字出版收入首次超过纸质出版，而我们的数字化人才储备仅为行业平均水平的60%。
**Q**：编辑团队需要什么新能力来应对这个结构性变化？
**A**：建议分两期推行'数字编辑赋能计划'——一期工具层（3个月），二期思维层（6个月）。
```

## 第 4 步：MECE 自检

检验金字塔的中层论点是否严谨。

### 两条标准

- **相互独立（Mutually Exclusive）**：3-5 个论点之间没有重叠。如果分不清"市场够大"和"增长够快"是不是同一件事，就合并或重新划分维度。
- **完全穷尽（Collectively Exhaustive）**：合在一起覆盖了问题的全部维度。检查是否漏掉了"竞争格局""监管风险""执行可行性"等常见遗漏维度。

### 常见 MECE 切割维度

| 维度 | 示例 |
|---|---|
| 时间 | 短期 / 中期 / 长期 |
| 空间 | 国内 / 海外；线上 / 线下 |
| 利益相关方 | 客户 / 员工 / 股东 / 监管 |
| 价值链 | 研发 → 生产 → 销售 → 售后 |
| 问题分解 | 是什么 / 为什么 / 怎么办 |
| 对比 | 内部因素 / 外部因素；优势 / 劣势 |

### 输出格式

```markdown
## MECE 自检

**切割维度**：[时间/空间/利益相关方/价值链/...]

**论点清单**：
1. [论点1] — 覆盖：[维度1]
2. [论点2] — 覆盖：[维度2]
3. [论点3] — 覆盖：[维度3]

**重叠检查**：论点1和论点3是否有交叉？→ [是/否]
**遗漏检查**：是否漏掉以下常见维度？→ 竞争格局 / 执行风险 / 外部政策 / ...
```

---

## 第 5 步：逐页大纲输出

将前面四步的成果转化为**可以直接交给 AI PPT 工具的逐页大纲**。

### 每页结构

```markdown
## 第 N 页：[结论式标题]

- **类型**：[封面/目录/SCQA情境/SCQA冲突/SCQA问题/核心结论/论点展开/证据支撑/案例/过渡/总结/行动号召]
- **核心观点**：[一句话]
- **支撑内容**：[数据/案例/引用]
- **视觉建议**：[大字报/对比/时间轴/流程图/图表/图文分栏/金句页]

### 页数分配参考

| PPT 总页数 | 建议分配 |
|---|---|
| 10 页 | SCQA开场2页 + 核心结论1页 + 论点3页 + 总结1页 + 封面结尾2页 |
| 20 页 | SCQA开场2页 + 核心结论1页 + 论点3页×1-2页支撑 + 案例1-2页 + 过渡页3页 + 总结1页 |
| 30 页+ | 按金字塔层级展开，每 5-7 页一个章节过渡页 |
```

### 质量标准

每一页的标题必须过两道测试：
1. **结论句测试**：标题是结论句还是话题句？——"市场增速放缓至4%"通过了，"市场分析"不通过。
2. **所以呢测试**：读完这页，听众离接受顶层结论更近了吗？——不近就删。

## 完整输出模板

完成五步后，将以上内容整合为一份**内容 Brief**：

```markdown
# [PPT 主题] —— 内容 Brief

## 基本信息
- 场景：[汇报/授课/路演/答辩/其他]
- 听众：[身份、已知信息、关心点]
- 时长：[分钟] ｜ 页数上限：[页]
- 形式：[投影演示/会后阅读/兼顾]
- 一句话核心：[金字塔顶层结论]

## 金字塔结构
[第 2 步输出]

## SCQA 开场
[第 3 步输出]

## MECE 自检
[第 4 步输出]

## 逐页大纲
[第 5 步输出]

## 约束清单
- 禁用词：[...]
- 敏感话题：[...]
- 必须包含：[...]
```

这份 Brief 可以直接作为任何 AI PPT 工具（或人工设计师）的输入。

## 反模式（这些做法回退到第 1 步）

- ❌ 用户说"帮我做一个关于 AI 的 PPT"就直接生成大纲——没聊透，生成的 80% 会废
- ❌ 金字塔写"一方面……另一方面……"这种模糊表述——每层必须是一句完整论断
- ❌ SCQA 的冲突写成"行业在变化"——冲突必须有具体数字或事件
- ❌ MECE 自检跳过——你会漏掉"执行风险""竞争格局"等最常见遗漏
- ❌ 逐页标题落回话题式——"市场分析""下一步计划"不通过结论句测试
